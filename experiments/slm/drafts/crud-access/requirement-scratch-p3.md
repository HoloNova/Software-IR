读者需要查看图书和公开文章，管理员负责图书目录，并维护自己撰写的文章。

查看图书目录不必登录，详情和分页列表对匿名开放；创建、更新、删除图书则仅限 ADMIN，匿名写入得到 401，READER 写入得到 403，而且必须先判断角色，再判断图书是否存在。

管理员建图书条目时只能提交 title，创建成功得到 201 与 id、title、stock，其中 stock 固定由服务端初始化为 5。

管理员更新图书时只提交 title，成功后收到 200，stock 保持原值；删除成功也收到 200，图书记录必须真正被删除。

若图书请求中夹带 stock，则返回 400；所有被拒绝的图书操作都不能让数据库发生改变。

读者不论匿名、READER 还是其他 ADMIN，都能查看公开的文章详情和分页列表；但 state=hidden 的文章不能列出，访问其详情要返回 404 PostNotFound。

管理员创建、修改或删除文章时，必须同时满足 ADMIN 角色和本人作者归属；匿名得到 401，错误角色得到 403，其他管理员也不能越权访问本人的写入路径，这种访问按 404 PostNotFound 处理。

作者创建文章时提交 body，author 取当前用户，文章的 state 默认是 open，version 从 1 开始。

作者用 PATCH 修改文章时提交 expectedVersion 和 changes.body，成功只改传入的内容，version 加一；若版本已经过旧，则返回 409 StalePost，不能覆盖文章的新值。

文章请求中若夹带 state，会得到 400；请求被拒或发生版本冲突时，数据库不能改动，state 仍保持 open。

作者删除自己的文章成功时收到 200，该文章记录被实际删除。

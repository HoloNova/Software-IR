SearchCourseEnrollments 通过 GET /api/search-course-enrollments 查询至少有一条 ACTIVE 报名的课程，每门课只出现一次，且 ACTIVE 必须属于这门课本身；只有 CANCELLED 或没有报名的课程不入选，按 code 升序分页。每项返回 id、code、name、capacity、doubledCapacity 及 enrollments，doubledCapacity 为该课 capacity 的两倍；enrollments 包含该课全部报名而不只 ACTIVE，按报名 id 升序且不截断，30 条也全部返回；报名含 id、status、active、student，active 表示自身 status 是否 ACTIVE，student 含 id、studentNo、name、label，label 等于该学生 name，不能串用其他课程或学生的值。响应为 total、page、size、records，total 统计匹配课程数而非报名数；page、size 默认 1、20，范围为 1～10000 和 1～100，超过末页为 200 空 records 且保留真实 total，page=0 返回 400 InvalidPage。一次有课程结果的请求恰好执行 4 次业务表读取：总数、当前页、按本页课程编号集合批量读报名、按所需学生编号集合批量读学生；空页只执行前 2 次，非法分页不读取业务表；不能逐门课或逐名学生额外读取，其他读取只能是连接会话变量探测。数据库中课程筛选必须体现与当前课程关联的存在性检查，报名和学生批量读取必须按已取得的编号集合筛选；一次请求的全部读取必须处于同一个只读事务，查询不得改变任何表。返回完整的 sir 0.3 文档，不要 Java、SQL 或解释。

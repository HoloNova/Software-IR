账号注册接收 name、password，返回 id、name、role，默认 STUDENT；登录返回访问及刷新令牌，期限为 15 分钟与 7 天，刷新令牌使用一次后失效，退出使刷新令牌失效；需身份的路由只接受有效访问令牌，匿名为 401。公开课程搜索接收 keyword、page、size，只列 published=true 且 name 或 code 字面包含 keyword 的课程，按 code、id 升序分页；返回含 teacher、capacity、enrolled、remaining、full 和周课表字段，remaining=capacity-enrolled，full 表示人数已达容量。只有 ADMIN 可创建课程、配置先修、发布和记录通过成绩，学生尝试这些操作均为 403 Forbidden，所有拒绝不得改变课程、选课、先修和成绩记录。创建课程接收 code、name、teacherId、capacity、weekday、startPeriod、endPeriod，成功返回 201 与课程字段，初始 published=false、enrolled=0；weekday 为 1～7、startPeriod 为 1～12、endPeriod 不超过 13 且必须大于 startPeriod、capacity 至少为 1；这些数值缺失或 null 返回 400 INVALID_REQUEST，fields 指明原字段路径及 NotNull，范围错误或空/倒序时段返回 400，不能落库。管理员可为未发布课程增加或删除任意多条直接先修要求，重复关系返回 409 PrerequisiteExists，自身或尚未发布的先修课返回 400 InvalidPrerequisite；发布成功为 200，之后增删先修或重复发布都返回 409 CoursePublished，不能改变既定课程要求。管理员向指定 studentId、courseId 追加通过记录，成功为 201，重复为 409 CompletionExists；刚提交的通过记录须立即影响后续选课，学生不能自报通过。本人选课接收课程 id，成功为 201 且保存唯一的学生/课程选课记录并占一个座位；未知课程为 404 CourseNotFound，未发布为 409 CourseNotOpen，重复为 409 AlreadyEnrolled，必须通过所有直接先修课程，否则为 409 MissingPrerequisites，不能用数量相等但课程不同的成绩集合冒充。同一学生同星期且半开节次区间重叠的选课返回 409 TimeConflict，首尾相接允许，不同星期互不冲突；同一学生并发选两门重叠课只能一个成功，另一个为 409 TimeConflict，等待该学生已有事务提交后须重新检查冲突并看到刚提交的选课。八名学生竞争三个座位恰好三个 201、五个 409 CourseFull；退课只允许本人，别人为 403 Forbidden，本人成功为 200 并删记录、释放一个座位，重复为 404 EnrollmentNotFound，八路并发退同一条记录只一个 200、七个 404，退后可以重选。课程 enrolled 始终等于实际选课数且在 0～capacity 内；选课晚发生唯一冲突时返回 409 AlreadyEnrolled 并撤销座位增加，退课晚发生外键删除失败时返回 500 并撤销座位减少，旧计数为零却有选课记录时为 409 EnrollmentCounterMismatch，不得删记录；所有失败都不改四类业务记录。选课必须在其他事务锁住该学生行时真实等待，不能绕过学生级串行检查；本人列表按 createdAt、id 降序，教师仅能查询自己课程的名单并按 createdAt、id 升序，越权为 403 Forbidden；分页响应统一为 total、page、size、records，默认 1/20、上限 10000/100，非法为 400 BadPage。返回完整的 sir 0.3 文档，不要 Java、SQL 或解释。

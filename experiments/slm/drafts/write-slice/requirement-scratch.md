CreateCourse 接收 code、name、可空 description、capacity，创建后返回 201 和 id、code、name、description、capacity、version，保存的初始 version 为 0；name 纯空白返回 400，错误指出 path=name，且不新增行。GetCourse 通过 id 查询，返回 200 和全部课程字段，未知 id 返回 404 且 code=CourseNotFound。UpdateCourse 使用 PATCH /api/update-course，接收 id、expectedVersion、changes，changes 只可包含 name、description、capacity；没传的字段保持原值，description 显式 null 才清空，code 不可修改；成功返回合并后的完整课程字段，version 从数据库当前值加一。必须按记录实际版本比较 expectedVersion，过旧返回 409 StaleVersion；两个持相同版本的请求竞争时恰有一个 200、另一个 409，数据库只更新一次，其他行不变；所有被拒请求均不写库、不推进版本。changes 为空返回 400 EmptyChange；id 不存在返回 404 CourseNotFound；缺 id 或 expectedVersion、未知外层字段或未知 changes 字段均为 400，错误中须指出缺失或未知字段路径；name 纯空白返回 400 INVALID_REQUEST，fields 中包含 path=changes.name、code=notBlank。返回完整的 sir 0.3 文档，不要 Java、SQL 或解释。

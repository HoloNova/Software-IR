GetCredential 按 UUID id 返回 id、owner、expiresAt，不存在返回 404 CredentialNotFound；凭据主键按标准 UUID 文本保存。Refresh 接收 token，仅允许未使用且未过期凭据轮换，原子地标记旧记录已使用并保存恰好一条 owner 相同、used=false、期限为当前起 7 天且主键为不同 UUID 的新记录，返回 id、owner、expiresAt；重放和未知 token 返回 409 Invalid，过期返回 400 Expired，失败不新增记录。Touch 接收 token，仅 owner 为 alice 时将 used 设为 true 并返回 200 与凭据字段；即使原值已为 true 仍须成功，owner 不符或 token 不存在为 409 Invalid 且不改行。FindAccount 按 name 查账号，唯一命中返回 200 和 id、name，未命中为 404 AccountNotFound；数据库因脏数据有同名多行时必须返回 500，不得任选一行。Register 接收 name、password，创建并保存账号，成功返回 id、name，不包含口令或摘要；数据库口令必须为带独立盐的 pbkdf2-sha256$ 格式摘要，不能存明文。Login 接收 name、password，正确口令返回 200 和账号 id、name；错误口令和不存在账号都返回完全相同的 401 BadLogin；数据库中不是摘要格式的旧文本，即使与输入相同也不得登录。返回完整的 sir 0.3 文档，不要 Java、SQL 或解释。

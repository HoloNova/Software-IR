# SIR Semantic Model 第三轮最终复核报告

日期：2026-07-14  
复核基线：`b018e2a` 之后的最终整改

## 1. 验收结论

第三轮 Semantic Model 在最终复核整改后通过验收，可以作为下一阶段 Lowering 设计的输入基线。

本结论只覆盖：Parser/AST、Resolve、Type、Validate、Normalize、符号/类型模型、诊断和确定性。它不表示 Lowering、Generator、Project Symbol Graph 持久化、Change SIR、Spring/MyBatis-Plus/Redis Extension 已经完成。

## 2. 最终修复

### 2.1 非法 Find 不再导致异常逃逸

未知 Entity 的 Find 会产生 `SIR-SYMBOL-002` 和 `SemanticAnalysis.Failure`。Resolve 在 Entity 类型缺失时不构造 `ListType(null)`。

### 2.2 名称引用具有稳定身份

- `AstNameRef` 现在实现 `AstNode`，拥有 AstNodeId、SourceSpan 和文本。
- Parser 根据结构父路径和引用角色生成稳定 ID。
- Entity、Error、变量目标、绑定字段、名称表达式和成员访问全部在 Resolve 阶段绑定到 SymbolId。
- Create/Load/Find 结果变量以产生它的 Step AstNodeId 绑定。
- 同一 AST 节点重复绑定立即抛出内部一致性错误。

### 2.3 Normalize 不重新解析名称

NormalizePass 已移除 Entity/Error/变量的 `byName`、`lookupInScope` 和 SymbolId 再构造逻辑，只消费 `referenceBindings`。Normalized Capability 的 fails 改为 `List<SymbolId>`。

### 2.4 Constraint 参数规则完成

- min/max 能确定求值带一层负号的整数和十进制字面量；
- length 只接受两个整数字面量；
- length 参数必须非负且 min 不大于 max；
- 十进制 length 和负数 length 产生单个 `SIR-TYPE-001`。

### 2.5 诊断所有权和唯一性

- 未知 Create/Update 字段只由 ResolvePass 诊断；
- TypePass 只消费已绑定字段进行类型兼容检查；
- identity 是已知字段，Create/Update 的禁止规则只由 ValidatePass 诊断；
- Normalize 对完全相同的最终诊断做稳定去重，作为防御性保证。

### 2.6 SymbolId 防重

SymbolTable 对任何重复 SymbolId 都 fail-fast，包括同一个 Symbol 实例被重复加入。

### 2.7 确定性测试加强

- Turkish Locale 测试比较完整诊断对象；
- 重复运行比较完整 referenceBindings、expressionTypes、Symbol 序列、Normalized declarations 和 diagnostics；
- 新增完整 Workflow 名称引用绑定测试和链式 MemberExpression 测试。

## 4. 新增回归场景

`RectificationRegressionTest` 从 20 项增至 28 项，新增覆盖：

1. 未知 Find Entity 返回 Failure 而非抛异常；
2. 负数 min/max 是合法数字常量；
3. 负数 min/max 冲突只产生 Validation 错误；
4. length 拒绝负数和 Decimal；
5. SymbolTable 拒绝同一 Symbol 的重复 ID；
6. Workflow 中 Entity/Error/变量/字段/结果声明均有绑定；
7. Update identity 只报告“禁止修改”，不报告“未知字段”；
8. `input.user.name` 链式 MemberExpression 正确解析。

## 5. 仍然存在的边界

以下是未实现范围，不是本轮失败：

- 多文件 import 和跨文件 Symbol Graph；
- AstNodeId 在文件移动/结构重写后的迁移协议；
- 算术常量表达式；
- if/else、循环和一般控制流；
- Lowered IR、Target Lowering 和 Generator；
- Spring Boot、MyBatis-Plus、Redis Extension；
- Change SIR、增量编译、Java 反向解析和用户代码保护区。

下一阶段不得通过让 Generator 读取 AST 或重新按名称解析来绕过当前语义边界。
